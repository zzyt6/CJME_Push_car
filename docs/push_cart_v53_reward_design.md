# V5.3 奖励修订 2：准确推车，限制有害波纹

本次修改针对用户提出的两个要求：加强对推车准确性与波纹的关注；力变化约束必须有适用阶段，不能压制起步、制动和转向所需的施力。

默认配置先强化车速跟踪和分轴误差波纹。另提供 `v53_wrench_guarded` 条件施力实验，默认关闭。**减少车速跟踪误差的波纹，有助于减小运动抖动；仅让曲线平滑，并不能保证响应及时、位置准确或转向准确。** 当前没有完成使用新奖励的完整训练，不能声称已经找到最优施力方式。

## 为什么不使用通用的力变化惩罚

`||F(t)-F(t-1)||²` 会同时惩罚有害振荡与必要的作用力变化。起步要克服静摩擦，制动要改变力的方向，转向需要力矩，恒速转弯也需要随航向改变的向心力；脚步、脚轮摆动或外界扰动发生时，变化的手部施力还可能正是在抵消这些扰动。

因此，不设置“力越小／越恒定越好”的通用目标，也不追踪一个仅靠 `F=ma` 给出的理想手力。手力、车轮地面作用、惯性和负载共同决定运动，理想手力不能仅从车速参考唯一求出。

既有过载、抬车、关节和姿态约束保留；它们保护物理可行性，与本次讨论的力变化奖励不同。`force_rate` 与无条件 `cart_wrench_osc` 在两个新训练配置中都为 0。

## 主目标：分别约束前向、侧向和偏航跟踪误差

定义 `e_c = v_cart - v_reference`，平移单位 m/s，偏航单位 rad/s。将平移误差转到世界固定坐标，分别进行两路一阶低通，再作差：

```text
alpha(f) = 1 - exp(-2*pi*f*dt)
LP_f(t) = LP_f(t-1) + alpha(f) * (e_world(t) - LP_f(t-1))
b_cart(t) = R_cart_from_world(t) * [LP_5Hz(t) - LP_0.5Hz(t)]
z_i = max(abs(b_i) - deadband_i, 0) / scale_i
cost_i = min(Huber(z_i), 4)
Huber(z) = 0.5*z², z <= 1; otherwise z - 0.5
```

这是**两个一阶低通之差**，不是理想的 0.5–5 Hz 带通，带外也有响应。使用世界固定坐标滤波，避免坐标旋转本身造成假的力／速度跳变。误差相对参考计算，因此准确跟随加速或转弯参考时，主波纹惩罚为零。

首个有效样本初始化滤波器；每个环境重置后，波纹项预热 1 秒。另有 0.08 秒低通的持续跟踪误差项：它从首个有效样本计分，不把恒定偏差误认为平滑成功。质量项沿用启动后 60 秒的整体权重渐增；指数跟踪和进度奖励全程有效。

| 项目 | 修订前 | 修订 2 默认 |
|---|---:|---:|
| 前向跟踪 `track_cart_vx` | 1.50 | **2.00** |
| 侧向／偏航跟踪 | 0.75 / 3.00 | 0.75 / 3.00 |
| 指令轴运动进度 `track_progress` | 1.00 | **1.25** |
| 合并平移波纹 `cart_lin_ripple` | −0.10，x/y 平均 | **0**，避免重复计分 |
| 前向波纹 `cart_vx_ripple` | 包含在合并项中 | **−0.25** |

参考滤波保持 0.4 秒、普通跟踪测量滤波保持 0.2 秒。没有通过拖慢参考来制造低波纹，也没有新增笼统的车体加速度／jerk 惩罚。保持进度奖励和持续误差约束，防止“原地不动也很平滑”。

## 条件施力项：只有很窄的适用范围

`v53_wrench_guarded` 额外启用以下实验。它约束车把中心处的合力／合力矩 `[Fx,Fy,Mz]` 的波纹，不逐只手惩罚力差分；差动力产生的转向力矩不被误当成双手相互浪费。

### 1. 阶段门控

以下条件必须同时满足：

- 参考和原始任务指令的前向速度绝对值均至少 0.10 m/s；静止、起步早期、停车指令阶段关闭。
- 原始指令相邻步变化不超过 0.005；指令变化立即关闭。
- 参考变化率逐轴不超过 `[0.08, 0.05, 0.08]`，单位分别为 m/s²、m/s²、rad/s²；加速、制动和换向的主要瞬态关闭。
- 原始指令与参考的侧向速度均不超过 0.03 m/s，偏航速度均不超过 0.03 rad/s；侧移和转弯关闭，包括恒速转弯。
- 没有施加中的机器人／车体外力脉冲，没有主动脚轮卡滞，力样本完整有效。

连续满足条件 **0.8 秒**后，权重在 **0.5 秒**内渐增到 1；任一条件失效立即归零。缺少指令、扰动状态或力有效性信息时也关闭。被排除的阶段会重置该项的力滤波历史，避免把起步大力留到恢复阶段再追罚。主车速／响应项不受这个开关影响。

这些条件根据任务参考与仿真扰动状态确定，不能通过“故意跟踪很差”关闭主奖励。已知扰动状态只进入训练奖励，不进入 Actor 或两个估计器的前向输入。

### 2. 车速没有波纹，就不惩罚变化的施力

对每个对应轴计算：

```text
co_ripple_i = clip((abs(velocity_error_band_i)-velocity_deadband_i)/velocity_scale_i, 0, 1)
force_axis_cost_i = min(Huber(max(abs(wrench_band_i)-wrench_deadband_i,0)/wrench_scale_i), 4)
guarded_cost = stage_gate * mean_i(co_ripple_i * force_axis_cost_i)
reward_force = -0.005 * guarded_cost * reward_ramp * dt
```

力尺度仍为 `[20 N,20 N,5 N·m]`，死区为 `[1 N,1 N,0.2 N·m]`。若施力变化而运动准确，`co_ripple=0`，不会受到这项惩罚；若力恒定，力波纹成本为 0。满权重时该辅助惩罚最多 **0.02 奖励／秒**，即 **0.0004／控制步**。

此处只检测力波纹与对应轴运动波纹的**共同出现，不证明因果关系**，也没有建模力和加速度之间的相位延迟。未显式标记的碰撞、路面变化和长时间恢复仍可能落在允许窗口内；小权重、主运动目标及默认关闭用于限制这种误判的影响。不能把 0.8 秒恢复时间当成所有接触情况的充分保护。

### 3. 力来源与采样限制

车速奖励使用仿真运动状态。力波纹使用手部子树牛顿欧拉动力学重建的手对车载荷，**不是独立测力传感器真值，也不是估力网络预测**。本次没有改变原始抓握、PD、手力重建公式或学习监督来源。

修订 2 的质量滤波器改用一个 20 ms 控制区间内的有效物理子步均值，减少直接下采样最后一个 5 ms 样本造成的混叠。条件力项要求四个子步完整；均值法不是理想抗混叠滤波，掌点在区间内移动时，力矩平移也只近似到一阶。使用各掌平均参考点合成到当前车把中心，坐标在元数据中明确记录为 `handle_center`，不再错误称为整车质心。

既有瞬时力预算和峰值／终止保护没有改成均值。动态接触载荷仍未独立校准，因此优先训练默认运动目标，再以条件力项作消融。

## 配置、旧模型与复现

默认从头训练采用 `v53`。启用条件力实验需要明确选择另一配置：

```powershell
# 默认：加强跟踪和误差波纹，不惩罚力变化
.\run_v53_pushcart_train.ps1 -RunName v53_motion_quality --quality_profile v53

# 消融：相同主奖励，增加很弱的条件施力波纹
.\run_v53_pushcart_train.ps1 -RunName v53_guarded_force --quality_profile v53_wrench_guarded

# 新采集 Isaac 轨迹，检查实际奖励占比和阶段开关
& E:\envs\RLisaac601\python.exe scripts/audit_pushcart_v53_rewards.py --viz none --device cuda:0
```

两种配置均会明确清除无条件 `force_rate`、`cart_wrench_osc` 和合并平移项，配置切换不会遗留另一组奖励。细节可通过原有 Hydra 参数覆盖。

V5.2 原有代码未修改。保存配置的 V5.3 修订 1 模型恢复时，新增的分轴项与条件力项补为 0，恢复原采样方式，避免叠加旧合并项；显式指定 `--quality_profile` 才迁移到新奖励。模型输入结构不变，仍为每帧 156 维。

正式效果验证应在相同种子、课程、物理随机化和训练预算下比较旧主奖励、新主奖励、增加条件力项三组。每组需多种子、独立新轨迹，并分别记录前向／侧向／偏航误差、波纹、起步响应、停车距离和反弹、转向延迟与超调，以及逐手各轴受力与过载次数。若波纹下降而响应变慢、转弯变差或停止距离增加，应降低波纹权重，或关闭条件力项；不能只凭平滑曲线判定成功。
