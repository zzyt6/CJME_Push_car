## 驱动解释

原HOMIE训练也是腿力矩＋上身位置的混合驱动；公开部署通过 `q,dq,kp,kd,tau` 驱动电机。隐式位置训练不排斥sim2real，但PhysX隐式求解不等于实际伺服的时延、带宽和限幅，仍需实际验证。显式PD同样使用Kp/Kd；它在程序外部算力矩，native stiffness/damping置零是避免双重PD。V6此轮恢复已明确的V3.2接口，不把“参考官方”解释成更换增益的授权。
