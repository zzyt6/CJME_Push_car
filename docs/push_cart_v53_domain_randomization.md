# V5.3 域随机化修订 3：参考 HOMIE 的比例，补齐推车与观测覆盖

本次已修改训练代码，默认新训练采用 `homie_relative`。目标是扩大模型误差和测量误差的覆盖，而不是假定所有参数越随机越好。**原先并非全部范围都小：机器人动力学大部分已经等同 HOMIE，明显不足主要在高层观测噪声、固定空车质量和缺少脚轮差异。** 扩大域随机化不能单独证明真机可部署；本次先核验仿真参数与训练链路。

## 参考来源与原先的实际情况

直接核对了本仓库 HOMIE 原始配置 [g1_29dof_config.py](../HomieRL/legged_gym/legged_gym/envs/g1/g1_29dof_config.py) 和 Isaac 移植配置 [config.py](../HomieRL/homie_isaaclab/config.py)。两者有关范围一致。V5.3 通过 `G1RoughCfg` 继承这些机器人配置，显式 PD 已让腰部、双臂和下肢都实际使用随机增益／力矩扰动。

| 机器人参数 | HOMIE | 原 V5.3 | 本次处理 |
|---|---|---|---|
| 连杆质量倍率 | 0.8–1.2 | 相同 | 保留；惯量随质量缩放 |
| Kp / Kd 倍率 | 0.9–1.1 | 相同 | 保留，全身 27 关节 |
| 驱动力矩偏置／逐步扰动 | 各为关节力矩上限 ±5% | 相同 | 保留；这是附加力矩，不是电机增益倍率 |
| 机器人接触摩擦系数 | 0.1–3.0 | 相同 | 保留 |
| 机器人恢复系数 | 0–1 | 相同 | 保留；未复制到刚性推车轮胎 |
| 躯干附加质量 | −5 至 +10 kg | 相同 | 同一 G1 模型，保留 |
| 手部附加质量 | −0.1 至 +0.3 kg | 相同 | 保留现有正质量保护 |
| 躯干局部质心偏移 | 每轴 ±0.1 m | 相同 | 保留 |
| 下层执行延迟 | 0–3 个 5 ms 物理子步 | 相同 | 保留，0–15 ms |
| 机器人推扰 | 每 4 s，幅度参数 0.5 m/s | 相同幅度参数 | 保留质量×速度增量的力脉冲实现 |

HOMIE 的原始推扰直接改写根速度，推车任务以等量级的 `m·Δv` 外力脉冲实现；二者并非逐轨迹等价。原始 HOMIE 对自由站立机器人的初始关节／根速度扰动，也不能直接用于双手与车组成闭链的初始化。本任务仍保留校准抓握姿态，不随机破坏闭链；机器人与车作为整体随机平移／转动。

机器人质量和质心主要在环境创建时随机，增益、偏置、材料等按继承的 HOMIE 路径更新。机器人现有范围未另加一套放大倍率。

## 推车改动：按标称参数缩放

当前资产空车总质量约 **14.4 kg**，其中车体 12 kg，另有四组脚轮。车轮标称摩擦系数 0.8，滚动阻尼 0.005 N·m·s/rad，转向阻尼 0.05 N·m·s/rad。

| 推车参数 | 原先 | 修订 3 完整课程范围 | 依据 |
|---|---|---|---|
| 空车各连杆质量 | 固定 | 各自标称值 × **0.8–1.2** | HOMIE 连杆质量比例 |
| 空车各连杆惯量 | 固定 | 与各自质量倍率一起缩放 | 保持同一几何形状下质量／惯量一致 |
| 车轮材料摩擦系数 | 0.4–1.2 | 0.8 × **0.1–3.0** = **0.08–2.4** | HOMIE 标称系数 1 的相对范围 |
| 滚动阻尼 | 0.002–0.020，四轮相同 | 保留原基础范围，每轮独立 × **0.9–1.1**；最终 **0.0018–0.022** | 原工况范围已宽于 HOMIE 的增益比例；增加制造差异 |
| 转向阻尼 | 0.020–0.150，四轮相同 | 保留原基础范围，每轴独立 × **0.9–1.1**；最终 **0.018–0.165** | 同上 |
| 载荷放置的 XY 偏移 | 两轴 ±0.10 m | 车板两轴全长的 ±20%，即 **±0.196 / ±0.104 m** | 推车几何适配的工程假设，不是 HOMIE 原参数 |
| 自动车体外力 | 固定力幅值上限 25 N，间隔约 5 s | 每轴等效 `Δv∈[−0.5,+0.5] m/s`，按 **F=M·Δv/T** 计算；间隔约 4 s | 借鉴 HOMIE 的扰动速度尺度，并适配当前整车质量 |

载荷本身沿用课程的 0–5 kg 至 0–25 kg；这个工况跨度已经较大，不再因为增大随机化而盲目翻倍。计入新的空车质量不确定性，完整范围下整车总质量理论上约为 **11.52–42.28 kg**。载荷偏移表示载荷相对车体原质心的放置偏移，合成质心按质量加权移动，不能把 ±0.196 m 误认为整车质心总能移动这么多。

20 ms 控制间隔内执行的车体力脉冲沿用 0.20 s 持续时间。例如总质量 14.4 kg 时，最大每轴力幅值约 36 N；42.28 kg 时约 105.7 N，形成相同量级的单位质量冲量。实际有地面、抓握和机器人约束，真实速度变化不等于公式中的自由体等效 `Δv`。额外扭矩上限 3 N·m、偏心施力位置 ±0.2 m、轮卡滞倍数 20 保留，不把所有扰动幅度同时翻倍。

材料摩擦系数不是有效地面接触系数：当前地面系数为 1，PhysX 默认平均组合时，车轮 0.08–2.4 大致对应有效 0.54–1.7。改变组合规则或地面材料会改变这个映射。本次没有宣称覆盖了实际结冰地面的低摩擦。

## 高层与两个估计器的输入增强

以下是归一化之前、均匀噪声的最大绝对幅度。HOMIE 下层原有噪声照常保留；新的幅度用于高层 Actor 和两个估计器共同使用的可观测帧。

| 输入 | 修订前 | 完整课程下的新幅度 |
|---|---:|---:|
| 全身关节位置 | ±0.001 rad | **±0.02 rad**，HOMIE 幅度 |
| 全身关节速度 | ±0.02 rad/s，上身另有 ±0.3 | **±2.0 rad/s**，HOMIE 幅度；删除重复的上身附加噪声 |
| IMU 角速度 | ±0.01 rad/s | **±0.5 rad/s**，HOMIE 幅度 |
| 投影重力向量 | 每分量 ±0.005 | **±0.05**，HOMIE 幅度 |
| 视觉相对朝向逐步误差 | ±2° | **±3°** |
| 视觉朝向每回合固定偏置 | 无 | **±3°** |
| 视觉延迟 | 0–2 控制步，0–40 ms | **0–4 控制步，0–80 ms** |
| 视觉随机丢帧 | 5% | **10%** |

HOMIE 没有推车视觉接口，视觉数值是待校准的工程训练假设，不冒称来自 HOMIE。偏置在同一回合内保持不变，防止仅用独立白噪声代替视觉标定误差。朝向最大接受年龄仍为 0.12 s，无效数据仍通过有效性标志处理，不回退到抓握几何真值。

力矩读数原有的 ±5% 增益误差、按力矩上限缩放的 ±5% 固定偏置／逐步噪声，以及 0–40 ms 读取延迟保留。HOMIE 的 ±5% 驱动力矩扰动和这些观测误差是不同机制，不能混为一个物理量；观测误差范围仍是训练假设。HIM 速度输入继续来自真实运行的冻结估计器，没有注入车速真值。

这些是鲁棒训练增强，**不是声称真实编码器一定有 2 rad/s 误差或陀螺仪有 0.5 rad/s 误差**。网络需要重新训练适应这些输入；旧权重不会因修改配置自动获得鲁棒性。

## 课程、关闭开关和实现一致性

推车模型不确定性幅度使用：

```text
fraction = 0.25 + 0.75 * clip(level / 13, 0, 1)
current_bound = nominal + fraction * (full_bound - nominal)
```

因此第 0 级质量倍率约 0.95–1.05、车轮材料摩擦约 0.62–1.20；第 13 级达到完整范围。载荷工况和转向任务沿用原课程。高层关节／IMU／视觉噪声使用原观测噪声课程：第 0–7 级为 0，第 8–13 级从 1/6 增至完整幅度。机器人原有动力学随机化仍使用 HOMIE 范围。

自动外力与卡滞继续沿原扰动课程逐步开启。其随机强度取决于参考配置和课程，不通过学习式力估计器控制。

同时修复了以下实现问题：

- `--no_randomization` / `enable_randomization=false` 现在同时关闭推车质量／摩擦／阻尼／偏载／初始位姿／自动外力／卡滞，以及高层动作和力矩读数延迟。以前它主要关掉 HOMIE 的随机化，部分推车采样和延迟仍在运行。
- 关闭后使用 14.4 kg 空车、摩擦 0.8、滚动阻尼 0.005、转向阻尼 0.05；明确设置 `fixed_payload_kg` 的实验仍保留该负载。任务指令采样与 PPO 动作探索不属于这个物理开关，配对实验需要另外固定指令和策略。
- 每个脚轮独立保存阻尼；卡滞结束后恢复该轮自己的值，不恢复成四轮平均值。
- 新物理路径先设置质心姿态，再设置完整惯量矩阵。PhysX 设置惯量时会更新惯性主轴；旧的反向顺序会覆盖刚算出的主轴，破坏偏载的非对角惯量。新路径读回验证了实际惯量与模型缓存一致。
- 重置使用未随机化的标称质量／惯量重新构造，避免多次重置累计放大。局部重置不改写其他环境的物理参数。
- 保持 156 维观测接口。新增真实域参数仅用于物理、奖励、标签、已有 Critic 概括量和诊断；没有把真实质量／摩擦送入两个估计器的前向输入。Critic 的阻尼通道继续表示四轮平均值。

`grasp_threshold_jitter` 依旧只是失效判据随机化；固定抓握约束、抓握点、滑移模型均未随机化。手臂实际柔顺性已有全身 PD ±10% 覆盖，但它不能替代真实抓握顺应性与滑移验证。推车轮胎恢复系数仍为 0：零标称量没有可照抄的倍数范围，不能把机器人脚部的 0–1 直接解释成推车参数。

## 启动和旧模型恢复

新训练默认已启用新配置，也可以明确指定：

```powershell
.\run_v53_pushcart_train.ps1 -Level 0 -RunName v53_homie_relative --domain_randomization_profile homie_relative
```

只做名义仿真对照：

```powershell
.\run_v53_pushcart_train.ps1 -NumEnvs 16 -MaxIterations 2 -RunName v53_nominal_check --no_randomization
```

V5.3 修订 1／2 检查点缺少新字段时，恢复为 `legacy` 分布，保留保存的观测噪声和旧惯量写入路径。需要迁移已有检查点时，明确添加 `--domain_randomization_profile homie_relative`，必要时重新指定较低课程级别。训练启动器会把新比例和观测增强参数写入保存配置；仅修改 `randomization.profile` 的底层单个字段不会替换已保存的观测噪声幅度。

域随机化／观测配置现在也进入课程检查点的签名；分布变化后保留级别、清空旧评估窗口，避免把旧分布的成绩拿来升级。历史检查点缺少该签名内容时也会重新累计窗口。`legacy` 保存旧分布不代表所有随机数和物理执行逐位复现；关闭随机化开关的修正适用于当前代码。

V5.2 原程序、权重和场景未修改。新增实现与采样逻辑位于 [domain_randomization.py](../HomieRL/homie_pushcart_v53/domain_randomization.py)，训练端集成位于 [task_env.py](../HomieRL/homie_pushcart_v53/task_env.py)。

## 仿真验证与边界

测试共 **79 项通过**，覆盖比例映射、课程、全开／全关、载荷质量与质心守恒、完整惯量张量、传感器幅度、视觉固定偏置、旧配置恢复及域变化后课程窗口失效，并回归奖励和估计器接口。

另外在 Isaac 检查课程初期、完整范围和关闭随机化三种模式。每组 32 环境，重复重置读取 PhysX 原始质量／质心／惯量／材料／阻尼，验证局部重置和卡滞恢复，再各运行 400 步。原始报告位于 `logs/bench/v53_domain_randomization/`，汇总见 [仿真检查报告](../logs/bench/v53_domain_randomization/comparison.md)。

新分布下还完成 16 环境、每次采样 64 步、2 次 PPO 更新的运行检查，课程第 13 级，完整观测增强已开启。它验证训练链路可运行，不是训练收敛、力估计精度或真机部署效果的证据。

恢复上述检查点后又完成 1 次更新，确认三个优化器、新范围与第 13 级课程状态能恢复。新旧分布切换时窗口应丢弃、相同分布恢复时窗口应保留，两种路径分别由测试和实际恢复日志核验。

完整训练后应在独立新轨迹中检查各轴车速误差、左右手各轴估力准确性、启停和转弯响应，并在 MuJoCo 中分别做标称对齐与域外压力测试。当前还未覆盖真实抓握滑移、轮胎变形、地面几何和视觉系统实测的相关误差；这些差异不能靠增大已有随机数范围消除。
