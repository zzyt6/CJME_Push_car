# 推车强化学习 V4 升级

V4 的训练升级现已实现：保留已有速度质量奖励，混合训练启停和左右转向，并为行进后的停车阶段提供有界的高层纠偏能力。高层策略从头训练、底层 HOMIE 冻结，actor 620 / critic 652 / action 18 的布局保持一致。实现验证见 [性能升级记录](../logs/bench/v4_motion_upgrade_20260922/report.md)，此前代码问题的修复见 [基础审查报告](../logs/bench/v4_code_review_20260922/report.md)。实际收益仍需完整训练后的同条件 bench 验收。

## 一起启用的训练升级

`--quality_profile v4` 同时启用质量奖励、首帧 force_rate 修复、命令序列和停车纠偏，不需要逐个选择实验分支。旧模型按自己的保存配置运行，缺少新开关的旧 V3/V3.1/V3.2/早期 V4 默认关闭这些新增机制。

### 训练命令覆盖瞬态

每个环境 reset 时独立选择本回合模式；当前课程允许时，概率为：

| 模式 | 比例 | 内容 |
|---|---:|---|
| 原随机命令 | 50% | 保留 vx/vy/wz 联合随机目标及原 zero_prob |
| 启停重启 | 25% | 直推 2–4 s → 精确零命令保持 3–5 s → 同速重启，重复 |
| 左右转向 | 25% | 保持前进速度，每隔 2–4 s 切换转向方向，初始左右方向随机 |

所有目标都限制在当前课程的可行范围。课程 0 全部静止；未开放转向时，对应模式回退原随机采样。降低课程后重新限幅，部分 reset 不影响其他环境的序列。固定 bench/eval 命令优先，不会被训练序列覆盖。载荷仍按原课程随机采样，最高阶段为 0–25 kg，不改成固定 25 kg。

### 停车后有界纠偏

原 gate 根据 `|cmd_ref| / 0.05` 衰减。V4 在**曾有非零任务命令后的 5 s 停车窗口**内，允许以运动检测结果补充 gate；初始静止不会因噪声或估计偏置开闸。窗口到期后必须重新出现非零任务命令才能再次获得纠偏资格。

检测只使用 actor 同一份延迟/带噪声把手相对位姿、HOMIE 估计速度、IMU 角速度与重力方向。它近似检测把手残余运动，不读取仿真的车速真值，也不冒充精确车质心速度。

- 用 0.8 s 窗口的最小二乘斜率抑制姿态差分噪声，补偿机器人平移和旋转项。
- 线运动达到 0.10 m/s 或转动达到 0.22 rad/s，持续 0.20 s 后激活。
- 低于 0.04 m/s 且 0.09 rad/s 持续 0.40 s 后关闭；渐开/渐关时间常数 0.15/0.25 s。
- 补充 gate 最大 0.25；原命令 gate 更大时仍以原 gate 为准。零参考时新增指令残差最多为 vx 0.10 m/s、vy 0.075 m/s、wz 0.125 rad/s，上肢偏移受原硬限位和速率限制。
- 窗口末尾 0.25 s 再平滑收回，避免估计偏置使门控永久开启。

上述门限是验证过的保守初值，不保证检测小于门限的运动或实机估计偏差。它开放的是供策略学习的动作能力，纠正方向仍由训练出来的策略决定，不等于已经自动获得更短的停止距离。

Isaac、MuJoCo 使用同一个 `IdleCorrectionTracker`，在每次观测后更新、下一步动作前读取。导出的 `hl_interface.json` 包含所需运行时状态、参数和时序；纯 actor ONNX 不包含这个外部 gate，部署时必须同步实现。

## 已保留的基础修复

1. `force_rate` 在每个环境回合的首个有效抓握力上建立基线，首帧不再把静态抓握力当成力突变；部分环境复位也独立处理。
2. 力信号与速度信号继续使用共同有效性掩码，并检查完整六维力/力矩。任一分量非有限时，该步质量奖励整体无效；这不等于从 PPO rollout 删除整个 transition。其他奖励和观测存在非有限值时明确报错，防止污染优化器。
3. reset 采用条件赋零清除陈旧 wrench，避免 `NaN * 0` 仍为 NaN。`force_rate` 不用异常样本更新历史，actor/critic 在观测裁剪前检查有限性。
4. 阶跃 bench 保留对原始命令的响应、参考曲线自身响应；另统计实际速度对动态 `cart_ref_*` 的完整/瞬态/稳态 RMSE、IAE、ISE。参考自身上升时间不能直接当作策略延迟。
5. 短时滤波响应误差新增切换后完整及瞬态 RMS/积分，原有稳态字段保留。瞬态按控制步端点 `(切换时刻, 切换时刻 + 1.5 s]` 统计；离散成本按有效控制步乘 dt 累计，并报告有效时长/覆盖率。速度误差积分不跨无效样本或时间缺口。
6. 停车要求记录末尾连续低于 `0.05 m/s` 至少 `0.5 s`；之前短暂停住后回弹不能算最终停稳。首次低速、首次确认、最终确认分别记录，增加确认后移动、回弹事件数与超阈值样本数。未确认时 `stopping_distance=null`；路径缺失时也不伪造距离。
7. 阶跃整定同样要求最后入带区间保持至少 `0.5 s`；最后一个样本入带不能算已整定。bench 命令切换使用整数控制步，修正累计浮点误差造成的 1 步延迟，记录实际 `command_switch_s`。
8. 官方 play/resume 先确定实际检查点，再恢复同一运行保存的 task、HOMIE、网络和 PPO 配置；CLI/Hydra 显式覆盖优先。play 使用完整模型路径，scratch 不继承恢复变量。旧模型缺少 V4 开关时保持旧的首帧奖励行为。
9. 报告将确认状态显示为确认率，区分缺失/未确认，不把旧首次低速距离重命名为最终停稳距离。相同迭代数、不同版本的曲线图例保留运行名称；显式 bench `--level 0` 不再被误当成默认 17。

## 一键从头训练

在 PowerShell 中运行：

```powershell
.\run_one_stage_pushcart.ps1 train `
  --quality_profile v4 `
  --level 0 --num_envs 4096 --max_iterations 20000 `
  --run_name v4_speed_quality_scratch --headless
```

也可以直接运行一键脚本：

```powershell
.\run_v4_pushcart_train.ps1
```

`v4` 使用当前 combined 的权重：`cart_lin_ripple=-0.10`、`cart_yaw_ripple=-0.15`、`cart_response_error=-0.10`、`cart_wrench_osc=-0.02`，旧的合并 `cart_ripple` 保持关闭。它是从头训练命令，不带 `--checkpoint`。

从头训练指高层推车策略重新初始化；底层 HOMIE 仍加载冻结的已训练模型。运行名使用 `--run_name`，默认模型目录仍为 `logs/rsl_rl/homie_pushcart`。

## 保留的限制

- Isaac 的已知载荷响应已验证，动态惯性/手指重力矩补偿仍未实现，保留代理测力标识。
- 停车纠偏已实现且有时间/幅度边界；初始静止与窗口到期后仍使用原 gate，不承担无限时间静止抗扰任务。
- 满噪声、随机物理参数下，冻结 HOMIE 的零命令基线仍有漂移；同种子对照中 V4 初始静止行为与关闭纠偏完全一致。本次没有修复底层 HOMIE 的这一既有限制。
- 标准 PPO checkpoint 不保存动态课程进度；续训恢复保存的初始课程或显式 `--level`，不会自动恢复中断前已升到的课程。从头训练不受影响。
- 本机上游 IsaacLab 的 `train --cfg job` 在打印配置后有 `KeyError: env_cfg`；正式训练已验证通过，未修改外部 IsaacLab。
