# V5.2 sim2sim 场景对齐与力估计核验

日期：2026-09-27。只修改测评场景/接口及旧检查点配置恢复，没有重新训练策略或估计器，没有依据预测结果拟合物理参数。

本页保留最初的场景对齐与 12 工况结果。后续已完成 [冻结 HOMIE 控制配置恢复与共同显式 PD 分支](push_cart_v52_control_alignment.md)，其实际对照显示旧估计器对驱动方式敏感，物理响应仍未一致。下面的上身驱动说明对应旧检查点默认的 `training` 模式。

## 已修正的差异

| 项目 | 旧 MuJoCo 测评 | 当前 `isaac` 场景配置 |
|---|---|---|
| 机器人碰撞 | 躯干、手臂、手腕等存在碰撞体；每脚四个球 | 按训练 URDF，只保留两只脚的碰撞网格，过滤机器人与车接触 |
| 上身执行器 | 每个子步计算显式 PD 力矩并写入 motor | 原生位置 PD，`implicitfast`；下肢保留显式力矩接口 |
| 力矩观测 | `data.ctrl` 中的力矩 | 独立保存子步开始时裁剪后的 PD 代理；原生位置执行器的 `ctrl` 是目标角度，不能当力矩 |
| 机器人附加关节动力学 | `frictionloss=0.1`、被动 damping=0.001 | 对应训练的被动关节摩擦/阻尼为 0，保留转子惯量 0.01 |
| 车轮和脚轮 | 附加 armature=0.0005、干摩擦 0.02/0.01 | 按训练 URDF/运行时，附加惯量与干摩擦均为 0，保留黏性轮阻 |
| 腰限位 | ±2.618 rad | 训练 URDF 的 ±0.6 rad；其他关节同样从 URDF 读取 |
| 机器人惯性参数 | 原始通用 `g1.xml` 的合并、舍入参数 | 从实际训练的抓握 URDF 重建质量、COM 和完整惯量，正确合并固定掌部/头部等 |
| 载荷惯量/COM | 按总质量比例放大整车惯量 | 0.4×0.3×0.2 m 载荷箱，包含偏心载荷的平行轴项和质量加权 COM |
| 整车质量统计 | 只统计车身 | 包含脚轮/轮子，空载 14.4 kg |
| 摩擦组合 | MuJoCo 默认最大值，附加滚动/扭转摩擦 | PhysX 运行时脚材质 0.5、地面 1、轮子 0.8；显式接触对使用平均值 0.75/0.9，无额外滚动/扭转项 |
| 刚体阻尼 | 无 | 根据训练设置加入 0.01 线性/角速度阻尼对应的 COM 载荷近似 |
| 采样时间/速度参考点 | `mj_step` 后部分派生位姿仍是最后子步开始时的值 | 记录约束标签后刷新运动学；车速从 COM 换算至车体几何原点 |

生成场景位于 `.cache/pushcart_sim2sim/isaac_<hash>.xml`，以源资产/版本内容生成缓存，不覆盖训练 USD、旧 MJCF 或既有测评结果。源参数来自 `assets/g1_pushcart_v5/generated_urdf`，实际 PhysX 运行核对了质量、刚体阻尼、材料、关节摩擦、轮子附加惯量和上身 PD 增益。

**这不等于两个物理引擎数值一致。** MuJoCo 原生 PD/implicitfast 与 PhysX 隐式驱动离散化仍不同；MuJoCo 软 weld、接触求解和凸包处理也不等于 PhysX TGS。未通过调节约束参数追求更高预测分数。

## 检查点恢复问题

现有 `2026-09-26_01-56-48_v52_hand_estimator_20k/model_19999.pt` 训练配置早于新增力矩传感器模型。旧配置缺失字段时曾继承当前默认读数延迟等项；即使关闭 `cfg.noise.add_noise`，读数延迟仍会在环境 reset 中采样。现已为缺失的四个新增传感器字段恢复旧值 0，保留原有 ±5% 乘性噪声设置；新训练默认参数不变，显式保存的新字段仍按保存值加载。

本报告的两引擎测评明确关闭观测噪声和延迟，使用同一检查点和冻结的 HOMIE 60000。历史上把旧配置与新延迟混用的分数不用于本报告结论。

## 观测和标签核验

- 同一传感样本分别执行 Isaac 和 MuJoCo 的实际观测组装函数：完整 20×136 输入在 2e-6 容差内一致，包含历史、reset 和静力先验。
- MuJoCo 在每个物理子步上独立用递归 Newton–Euler 逆动力学、执行器/被动力矩和外加载荷重建手部扳手，不读取 `efc_force` 或 `qfrc_constraint`。包含 RNE 本身省略的转子惯量项，并使用与求解器一致的子步开始速度。
- 在 48,000 个逐手样本上，与 weld 约束力映射到掌原点的标签比较：三个力轴 RMS 差异均小于 5e-11 N；三个力矩轴 RMS 差异约 0.072/0.043/0.079 N·m。力矩不是严格零差，软 weld 的有限锚点分离等仍有影响。
- 该检查证明当前 MuJoCo 内两种力学重建基本一致，不代表已经完成 PhysX 手子树代理在双手闭链全动态范围的标定，也不把 MuJoCo 的 RNE 审计称作真实的 PhysX 关节传感器。

## 固定模型的同条件评测

三种额外载荷 0/12.5/25 kg，四种命令：直行 0.3、直行 0.6 m/s、0.3 m/s 下左右转弯 ±0.3 rad/s。每工况 500 控制步（10 s），前 2 s 为预热。观测噪声/延迟与域随机化关闭，固定初始脚轮角 0，标称轮阻与居中载荷。每配置有效样本 4,800。

评测读数由同一双手均值标签按照固定抓握几何合成把手中心 `[Fx, Fy, Mz]`。各场景闭环轨迹不同；这不是逐状态误差配对，也不是多种子训练优势证明。

结果及配置分别保存为 `logs/bench/v52_sim2sim_alignment/legacy.json`（旧 MuJoCo）、`isaac.json`（对齐参数的 MuJoCo）和 `physx.json`（Isaac）。数值汇总见 [comparison.md](../logs/bench/v52_sim2sim_alignment/comparison.md)。三组均完成 12/12 工况、各 4,800 个有效样本，没有记录到任务失败。

| 评测场景 | Fx R² | Fy R² | Mz R² | Fx RMSE (N) | Fy RMSE (N) | Mz RMSE (N·m) |
|---|---:|---:|---:|---:|---:|---:|
| Isaac / PhysX | 0.9984 | 0.9934 | 0.9992 | 1.142 | 1.181 | 0.157 |
| 旧 MuJoCo | 0.5617 | 0.1284 | 0.7679 | 16.192 | 12.412 | 2.397 |
| 对齐参数后的 MuJoCo | 0.5073 | -1.0473 | 0.6167 | 19.441 | 14.999 | 3.075 |

**参数一致性改进没有自动解决力估计迁移。** 旧 MuJoCo 的合载荷 R² 为约 0.562/0.128/0.768；对齐场景为约 0.507/−1.047/0.617，侧向力明显变差。负 R² 表示该分量误差大于用标签均值预测的误差。这些结果全部保留，不以错误的旧场景分数更高为理由恢复额外碰撞/错误惯量。

后续应单独研究上身实际驱动与观测力矩代理的关系、闭链动态标签标定，以及执行器/接触参数随机化对迁移的影响。不能仅凭训练内高 R² 认定估计器已具备真实测力或跨引擎能力。
