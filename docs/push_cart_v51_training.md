# V5.1 交互估计训练：命令与实现状态

日期：2026-09-25。本页对应 `HomieRL/homie_pushcart_v51` 的实际实现。原 V4、V5 revision 2 的源码和启动入口保持原样；新模型使用独立任务、配置与日志，不兼容直接加载旧高层 Actor。

## 从头训练

在 PowerShell 中执行：

```powershell
cd E:\CJME_Push_car

.\run_v51_pushcart_train.ps1 `
    -NumEnvs 4096 `
    -MaxIterations 20000 `
    -Level 0 `
    -Seed 1 `
    -RunName v51_interaction_privileged_20k
```

从 level 0 开始自动课程，最多运行 20,000 次 PPO 更新。每次 rollout 为 24 步、控制周期 20 ms，预算约 19.66 亿条环境转移。20,000 是预算，不是收敛证明；短测试只检查执行链路。建议每 500–1000 次更新检查固定验证集及课程进展。

该命令不加载旧高层检查点。Actor、交互编码器、载荷预测头和 Critic 从头训练；冻结 HOMIE/HIM，加载既有 `model_60000.pt`。高层仍输出 3 维速度残差和 15 维上身残差，全部可训练。

模型保存在 `logs/rsl_rl/homie_pushcart_v51/<时间>_v51_interaction_privileged_20k/`，每 200 次更新保存一次，结束时也保存。`params/env.yaml`、`params/agent.yaml` 和 `pushcart_task.json` 记录观测、物理接口、网络及辅助损失配置。

## 本次真正接入的内容

| 部分 | 实际实现 |
|---|---|
| 观测来源 | 关节编码器/IMU 的模拟测量、HIM 基座速度、固定抓握 FK、控制命令与动作历史；不读真实车位姿、车质量或接触力作为 Actor 输入。 |
| 历史编码器 | 124 维单帧 × 20 帧，共 2480 维外部输入；MLP 编码为 16 维交互表征。 |
| 载荷预测头 | 输出归一化的前后力、侧向力、绕把手中心的转向力矩，尺度为 `[80 N, 80 N, 12 N·m]`。 |
| Actor 决策网络 | 当前 124 维观测 + 16 维表征 + 3 维预测载荷 = 143 维，输出 18 维动作。 |
| Critic | 当前 124 维观测 + 46 维特权信息 = 170 维。包含两手力/力矩、实际施加的车侧外力/力矩和机器人侧外力/力矩，以及真实任务速度、载荷/摩擦等。 |
| 辅助监督 | 单独的 `interaction_target=[Fx/80,Fy/80,Mz/12,valid]`，只参与 Huber 损失；默认 `aux_coef=0.1`，同时训练编码器和预测头。Actor 始终用预测值。 |
| 数据时序 | 每次 PPO 更新重新从 rollout 中保存的因果历史计算编码器；标签与采样前观测配对，回合 reset 不修改 PPO 持有的上一时刻标签。 |
| 运动参考点 | 车体 base-link 固定几何原点，不是随载荷变化的整车 COM。比较旧版时必须统一该定义。 |
| 恢复权限 | 由可观测运动、倾斜和角速度触发有界权限，支持初始静止及持续偏差，不依赖真实外扰时刻。 |
| 训练物理计算 | 200 Hz 物理积分和局部手子树补偿；50 Hz 策略。默认关闭全身动量、足轮逐接触扳手、全量冲量与轨迹审计。 |

Critic 中手载荷来自仿真关节扳手的 Newton–Euler 补偿估计，是当前交互载荷代理；额外施加的外扰来自实际提交给仿真的载荷记录。两者不是同一种量，不能将外扰计划值代替手车接触力。

手力和手力矩表达在车朝向坐标中，单手力矩参考点是掌原点；辅助合载荷和车侧外扰力矩的参考点是把手中心；机器人外扰参考骨盆 COM。Critic 的基座速度保留骨盆坐标表达。Actor 的坐标和速度换算只使用 FK/IMU 估计链。

当前关闭 V5 的名义力解析速度补偿和 `task_wrench`、`reaction_motion`、`centroidal_recovery`、`support_feasibility` 四项奖励，也关闭 `force_waste`、`cart_yaw_lead` 和无差别力变化惩罚；保留任务跟踪、进度、停车、既有速度质量、执行器/关节/过载限制和动作正则。

## 观测噪声与标签边界

高层与 FK 共用独立编码器/IMU 模拟测量：均匀噪声幅度分别为关节角 0.001 rad、关节速度 0.02 rad/s、陀螺仪 0.01 rad/s、重力方向分量 0.005。这是当前实验参数，不是硬件标定值。HOMIE 原有训练观测增强保持原样；它的较大关节速度噪声不能直接作为 FK 测量噪声。

上身力矩暂使用仿真执行力矩代理。当前未完成硬件力矩接口、所有传感器延迟/偏置模型、完整 MuJoCo 部署链改造；本命令是 Isaac 研究训练入口，不能据此宣称已经真机可用。新 CLI 仅开放 train/play，既有 V5 资产作为只读输入，不开放重建入口。

已完成无车、已知外力/力矩、上肢运动及卸载的 200 Hz 数值核验，动态带载最大逐手力 RMS 约 0.00262 N、力矩 RMS 约 0.00045 N·m；这些结果只覆盖该测试的激励范围。因此当前允许以该载荷代理进行辅助学习实验，但 `dynamic_contact_wrench_calibrated=False` 保留，尚不能声称完整双手闭链、强冲击及接触切换都已标定。完整受载验证和恢复优势仍是后续实验任务。

## 等容量无力监督对照

```powershell
.\run_v51_pushcart_train.ps1 `
    -NumEnvs 4096 `
    -MaxIterations 20000 `
    -Level 0 `
    -Seed 1 `
    -RunName v51_history_no_force_supervision `
    -ExtraArgs 'agent.algorithm.aux_coef=0.0'
```

该对照保留相同网络、观测历史、Critic 特权信息与训练预算，仅关闭力标签损失。三个额外输出在该组中只能叫学习特征，不能继续当作校准过的力预测。主实验与该组比较才能隔离辅助监督的贡献。

## 续训

使用通用入口并指定真实检查点路径，避免从头训练包装器默认 level 0 覆盖恢复课程：

```powershell
.\run_v51_pushcart.ps1 train `
    --checkpoint 'E:/CJME_Push_car/logs/rsl_rl/homie_pushcart_v51/实际运行目录/model_2000.pt' `
    --num_envs 4096 `
    --max_iterations 5000 `
    --run_name v51_continue `
    --headless
```

路径示例需要替换。恢复网络、优化器、保存的任务配置及已完成回合的课程统计；进行中的物理回合重新开始。此处 5000 是本次继续运行的更新次数。若显式指定 `--level`，会覆盖恢复等级并清除不适用的课程窗口。

## 验证记录

- 4096 环境 × 3 次 PPO 更新通过，辅助损失正常更新并保存检查点；实测约 13,100–13,700 transitions/s。短测试不是稳定吞吐基准，也不是相对 V4 的同条件提速结论。
- 8 环境 × 240 步，满等级噪声及真实力脉冲下，FK 有效 1920/1920、力标签有效 1912/1920，8 次回合重置；已施加车侧外扰进入 Critic，重置历史与标签清空通过。
- 49 项 V5.1 单元测试通过，覆盖辅助梯度、Actor 特权隔离、无效标签、等容量消融、保存恢复、重置时 PPO 标签保留和包含编码器的 JIT 导出；FK 覆盖 yourdfpy 对照、有限差分速度、CUDA 及参考点换算。
- 最终 64 环境短训练和随后真实续训通过，已恢复 level 5、62 个已完成回合及完整课程统计窗口；这是恢复机制检查，主训练仍从 level 0 开始。
- 原 V4 40 文件快照和本次修改前 V5 46 文件快照均未变化。
