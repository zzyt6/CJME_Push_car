# V5.3：全身估力与学习式车速估计

本版实现用户指定的两个改动：估力观测扩展到全身 27 个关节的驱动力矩，删除车把相对位置；用独立的学习式车速估计器取代固定抓握运动学车速。车体相对朝向采用用户选定的视觉标记／车体姿态识别接口。

代码位于 `HomieRL/homie_pushcart_v53/`，任务注册为 `Homie-G1-PushCart-V53-Direct-v0`，训练日志写入 `logs/rsl_rl/homie_pushcart_v53/`。复用 V5.2 的物理场景、冻结 HOMIE 和课程模块；奖励在 V5.3 实现修订 2 中加入分轴波纹与条件施力实验，详见 [奖励设计说明](push_cart_v53_reward_design.md)。V5.2 的原始程序和权重没有被覆盖。本版输入和模型结构改变，不能直接加载 V5.2 Actor 或 680 维独立估力模型。

## 输入和部署来源

| 每帧输入 | 维度 | 真机对应来源 |
|---|---:|---|
| 全身关节位置、速度 | 54 | 27 个关节的编码器／驱动器反馈 |
| 全身关节驱动力矩 | 27 | 驱动器估计力矩／电流换算反馈；需要校准 |
| IMU 角速度、投影重力 | 6 | 机器人 IMU 与姿态滤波 |
| 身体速度估计 | 3 | 冻结的 HOMIE/HIM 预测 |
| 车体相对朝向 sin/cos、有效标志 | 3 | 标定后的视觉姿态与时间戳 |
| 任务参考、已应用 HOMIE 指令 | 6 | 控制器自身记录 |
| 已执行的上身位置目标 | 15 | 腰部和双臂 PD 目标 |
| 已执行的上一高层动作 | 18 | 高层控制器记录 |
| 已执行的上一下肢动作 | 12 | HOMIE 实际动作记录 |
| 双手 DLS 载荷提示 | 12 | 关节角度、手臂驱动力矩、机器人 URDF、IMU 与视觉朝向 |
| **总计** | **156** | |

没有车把位置、真实车速、真实车体位置、载荷质量、手部受力真值或固定抓握反推的朝向。`ObservableHistory.push` 只接受上述测量和控制信息，Isaac 与 MuJoCo 共用这个构造器。DLS 保留为辅助特征，依赖机器人手臂雅可比；它不读取 palm→cart 固定变换，不用于计算车速。DLS 的独立收益尚不能由此前的不同输入模型对比证明。

仿真使用 `applied_torque` 模拟驱动力矩读数，默认全身显式 PD，增加按关节上限缩放的噪声、每回合偏置和延迟。真机应接入 27 维驱动器反馈，不能把本体合力、约束反力当成电机力矩；仿真读数也不等于实际电流换算误差已校准。

## 视觉朝向接口

朝向定义为“车头 yaw − 机器人直立航向 yaw”，以弧度传入 `relative_yaw`，同时传入 `heading_valid` 和 `heading_age_s`。相机外参必须先把视觉测量转换到这个约定；当前完成了数据接口和仿真测量模型，没有实现依赖具体相机的标记检测程序。

仿真适配器只把真实相对 yaw 当成模拟视觉传感器的源信号。修订 3 在完整课程下使用逐步角度噪声 ±3°、每回合固定偏置 ±3°、0–4 个控制步延迟、10% 丢帧；最大接受年龄仍为 0.12 秒，并随观测噪声课程渐进。此前修订 1／2 使用 ±2°、0–2 步、5% 丢帧，恢复旧检查点时保留其配置。详见 [域随机化说明](push_cart_v53_domain_randomization.md)。这些是实验假设，不是真机标定结论。无效／过期测量使 sin/cos 和有效标志归零，不会回退到固定抓握或真实车速。控制参考和残差门控也遵从这个有效性标志，已发出的指令按原滤波／限速规则收回。

## 两个估计器和控制策略

车速网络取最近 5 帧的前 144 维（排除末尾 DLS），采用 `720 → 128 → 64 → 3` 的 ELU MLP。它借鉴 HIM 的“本体历史编码＋仿真速度监督”思路；本次没有复制 HIM 的潜变量原型／对比学习部分。

输出为车体 `base_link` 原点的 `[vx, vy, omega_z]`：平移速度表达在直立车头航向坐标轴，角速度为世界竖直轴分量，单位分别为 m/s、rad/s。内部尺度为乘 `[2,2,0.5]`，导出时恢复物理单位。这里不是车体质心速度；倾斜时 `omega_z` 也不应混称 Euler yaw 导数。

估力网络取最近 5 帧完整观测（780 维），拼接**当前预测车速** 3 维，采用 `783 → 512 → 256 → 128 → 12`。输出顺序仍为左手和右手各 `[Fx,Fy,Fz,Mx,My,Mz]`，各手掌原点、车头航向坐标轴、手对车方向。DLS 作为输入，不与网络输出强制相加。

两个输入归一化器分别统计各自可观测输入。高层 Actor 仍使用 20 帧历史编码，同时消费最新 156 维观测、16 维编码、预测车速和双手预测载荷。删除了 Actor 内依靠固定掌位移合成把手合力矩的通道。恢复门控改为基于 HIM 身体速度、IMU 和视觉朝向的身体运动判断；它不冒充学习式车速，也不读取真实车速。

## 监督与梯度隔离

`direct_env.py` 额外返回 `cart_velocity_target=[vx,vy,omega_z,valid]`（归一化后），与 `interaction_target` 分开保存。Actor 的观测组只包含 `policy`。真实车速可进入 Critic、奖励与独立监督目标，不能进入两个估计器的前向输入。

车速头用独立 Adam 和有效样本 MSE；估力头用另一个 Adam 和 12 维有效样本 Huber。PPO 优化器排除这两组参数。估力训练始终使用车速头的预测，并在拼接前 detach，既不把真值替换为车速输入，也不让估力损失更新车速头。两头参数、归一化统计以及三个优化器随检查点保存。

每次动作执行后构造同一采样时刻的观测和车速标签。手部监督仍来自四个 5 ms 物理子步的均值；启动阶段或重置附近不足四个有效子步的标签被屏蔽。局部重置会清空对应环境的历史、视觉延迟缓冲、力矩延迟缓冲和标签，不改写 PPO 已保存的上一时刻观测／标签。

## 运行

正式训练入口（本次未执行完整训练）：

```powershell
.\run_v53_pushcart_train.ps1 -NumEnvs 4096 -MaxIterations 20000 -Level 0 -Seed 1
```

有正式 V5.3 检查点后可导出或运行 MuJoCo：

```powershell
& E:\envs\RLisaac601\python.exe scripts/export_pushcart_v53.py --checkpoint <v53模型路径> --output logs/export/v53
& E:\envs\RLisaac601\python.exe scripts/eval_pushcart_v53_mujoco.py --checkpoint <v53模型路径> --steps 500 --output logs/bench/v53_eval
```

导出 JIT 的 `forward(history)` 返回高层动作，`physical_estimates(history)` 返回物理单位车速和双手载荷。输入历史由 `deploy_observation.ObservableHistory` 构造，需要本项目机器人 URDF。MuJoCo 继续采用 `nominal + urdf` 场景及显式 PD；本版没有更换抓握物理。
