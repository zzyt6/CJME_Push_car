2. **MuJoCo bench 上明显退化**：12.5 kg 时 V7 0.159 m，V6 0.034 m，直通 HOMIE 0.131 m。同样条件下，V7 在 Isaac 里是 0.066 m。

## 改动

### 1. 训练指令覆盖 bench 的需求（必做）

- **做法**：转向指令上限 `commands.wz_max` 从 0.4 提到 0.6 rad/s，和 bench 巡线器上限一致，即 HOMIE 训练范围的 75%。课程 `wz_ramp` 的终点随之到 0.6。
- **依据**：训练时转向指令最大 0.4 rad/s（V3.2 / V6 / V7 相同）。综合路线圆角半径 1.25 m、速度 0.5 m/s，本身就要 0.4 rad/s，有偏差时巡线器会要到 0.5–0.6。实测弯道里指令一直顶在 −0.6。在训练指令分布内，V7 的跟踪不比 V6 差（25 kg：wz RMSE 0.112 对 0.124）。差距只出现在超出训练范围的弯道。

### 2. 巡线式指令（可选）

- **做法**：30–50% 的环境用 bench 同款巡线器跟踪随机生成的路线（S 弯、直角、圆角绕行，半径 0.6–2.5 m），其余环境保持原有的分段常值指令。跟踪奖励不变。
- **依据**：训练指令每 4–6 s 换一个常值，没有连续变化和左右快速反向；bench 的 S 弯和绕行段正是这种情况。
- **风险**：V4 引入指令序列后精度下降，所以只占部分环境，单独验证。

### 3. 放松动作限制（必做）

- **做法**：`hl_action_clip` 去掉，或权重降到 −0.05 并只作用于均值。
- **依据**：按 V7 的奖励，V6 那种开法每秒因 `hl_action_clip` 多扣约 0.08 分。V7 的手臂动作幅度只有 V6 的 70%，饱和比例 6–7%（V6 19–20%）。超出训练范围的弯道需要用满动作。

### 4. 熵系数恢复 0.005（必做）

- **依据**：V7（0.002）的探索噪声约 0.24，V6（0.005）约 0.45。0.002 是 revision 8 为抑制被噪声化惩罚推大的 std 引入的；那些惩罚（绕管刚度、未滤波内力）已在 revision 8/9 修正。

### 5. 沿管滑移惩罚减半（可选）

- **做法**：`grasp_slip` −0.2 → −0.1。
- **依据**：V6 那种开法每秒因它多扣约 0.09 分。实机不脱手，轻微滑动是真实存在的。

### 6. 推车场景专用的机器人速度估计器（必做，2026-10-08 新增）

- **问题**：HOMIE 的 HIM 速度估计器是在机器人自己走路的数据上预训练的。推车场景下误差明显变大（MuJoCo，无噪声）：

  | 场景 | vx | vy |
  |---|---|---|
  | 单独行走（MAE） | 0.043 | 0.013 m/s |
  | 握车、不加高层（RMS） | 0.050 | 0.024 m/s |
  | 握车、V7 动手臂（RMS） | 0.080 | 0.082 m/s |

  Isaac 里同样如此（握车加 V7 时 vx / vy 约 0.10 m/s）。这一路进入高层观测；在 MuJoCo 里把它换成真实速度后，V7 在 12.5 kg 时从 0.159 m 降到 0.058 m。
- **做法**：
  1. HOMIE 原来的估计器和腿部网络保持冻结，继续负责走路。直接解冻它会改变腿部网络的输入分布，要连腿部网络一起微调，风险和工作量都大得多，不在本轮。
  2. 复制一份 HOMIE 估计器，用其预训练权重初始化，输入为同样的本体感知历史，部署时可得。
  3. 在推车训练中在线监督微调，目标为仿真真实骨盆速度（本体坐标），保留 HOMIE 原有的观测噪声和随机化。结构和训练方式参照现有的小车速度估计头 `CartHIMEstimator`。
  4. 它的输出替换高层观测里原来的 HOMIE 速度估计（`est_scaled` 与 `diff` 两个槽位），Actor 接口仍为 605 维。
- **验证**：握车加策略时，vy 误差在 Isaac 和 MuJoCo 中都接近单独行走的水平（约 0.02 m/s）；MuJoCo bench 12.5 kg 接近“换真实速度”时的 0.058 m。

### 7. 转向能力随机化（必做，2026-10-08 新增）

- **问题**：bench 退化的直接机理。开环对照（同样的固定高层动作）中，两个引擎里的小车响应大体一致，但同样的 HOMIE 转向指令，小车在 MuJoCo 里比 Isaac 少转约 15%（扣除漂移后 0.082 对 0.097 rad/s）。V7 在弯道没有余量，这点差异就让它掉线；V6 会在弯道减速，余量充足。在 MuJoCo 中把 HOMIE 的转向指令放大：

  | 倍数 | V7 12.5 / 25 kg | V6 12.5 / 25 kg |
  |---|---|---|
  | ×1.00 | 0.159 / 0.238 m | 0.037 / 0.090 m |
  | ×1.15 | 0.102 / 0.173 m | 0.035 / 0.054 m |
  | ×1.30 | 0.076 / 0.151 m | 0.026 / 0.041 m |

- **做法（实现时修改）**：原计划直接缩放发给 HOMIE 的转向指令，但缩放后的指令会出现在高层看到的 HOMIE 观测帧里，策略能直接读出“这一局被打了几折”，在实机和 MuJoCo 上学不到鲁棒性。改为物理等效：每局给小车加随机偏航阻尼 τ = −c·ωz，c ~ [0, 10] N·m·s/rad（随物理随机化课程逐步放宽）。MuJoCo 标定：c = 10 使无高层时的转向响应降低 18–29%（0–25 kg），覆盖实测的约 15% 引擎差异；0.2 rad/s 时约 2 N·m，与脚轮稳态转弯阻力同量级。
- **验证**：MuJoCo bench 中，V7 在 ×0.85 与 ×1.15 两种倍数下的结果差异不超过 V6 的水平。

### 撤回

- **给速度估计通道加偏差和更大噪声**：已撤回。同样条件下，Isaac 里的估计误差并不比 MuJoCo 小（Isaac 训练环境沿用了 HOMIE 观测噪声）；在 MuJoCo 补上相同噪声也没有让 V7 变好。由第 6 条替代。

## 评估与流程

- **短程筛选**：每个方案先跑 6000 次迭代（约 7.5 小时）。课程约 2000 次迭代到最高难度，弯道行为在 4000–6000 次可见。过关后再跑满 20000 次。
- **训练中自动评估**：每 1000 次迭代，在 MuJoCo 旧场景、MuJoCo V7 场景和 Isaac 路线上跑 0 / 12.5 / 25 kg 综合路线，按 bench 选 checkpoint。本轮第 4000 次迭代在 MuJoCo 12.5 kg 比第 10000 次更好，只看训练曲线发现不了。
- **通过标准**：
  - MuJoCo 综合路线前 19 m 横向误差，在旧场景和 V7 场景都不超过 V6（0 / 12.5 / 25 kg 约 0.05 / 0.04 / 0.09 m）。
  - Isaac 路线 25 kg 不超过 V6。
  - 第 6 条估计器的误差达到上面的验证标准。

## 已查明：bench 为什么变差（2026-10-08）

同一个 V7（model_10000）在 Isaac 12.5 kg 为 0.066 m，在 MuJoCo 为 0.159 m。逐项排除与确认：

| 怀疑项 | 结论 | 证据 |
|---|---|---|
| 小车 / 握持物理 | 已修正，不再是主因 | 转向轴摩擦、滚动阻力修正后，单体转向力矩两引擎一致；逐项替换不改变 V7 结果 |
| HOMIE 速度估计器 | 不是 | 单独行走 MuJoCo 与 Isaac 一样准；握车时 MuJoCo 误差不大于 Isaac |
| HOMIE 观测噪声差异 | 不是 | 在 MuJoCo 补上相同噪声，V7 没有变好 |
| 高层动作的开环效果 | 基本一致 | 固定动作下小车与人车相对航向的响应两引擎接近 |
| **转向能力余量** | **主因** | 同样转向指令，MuJoCo 小车少转约 15%；补回 15–30% 后 V7 恢复到接近 Isaac 水平，V6 不敏感 |

所以 bench 变差 = V7 弯道余量太薄（Isaac 里 25 kg 也只有 V6 的一半水平）× 两引擎间约 15% 的转向能力差异。改进第 1、3、4、7 条针对余量，第 6 条针对速度信息。

脚本：`scripts/action_response_v7.py`（固定动作响应）、`scripts/him_error_compare.py`（估计器误差）、`scripts/homie_mujoco_contact_audit.py`（单独行走）。
